# Decisions log

| Date | Decision | Reason |
|---|---|---|
| 2026-10-26 | Hosting: **Cloudflare Workers with static assets** (single project), not Pages. | Cloudflare now steers new projects to Workers; Pages is in maintenance mode. A Worker can serve the built site as static assets AND host the co-op Durable Object natively (Pages would need a separate Worker). Static asset requests are free and unlimited. |
| 2026-10-26 | Deploy through Cloudflare **Workers Builds** (Git integration); no GitHub Actions, no API tokens. | Required by brief; avoids secrets in a public repo. |
| 2026-10-26 | M1 `wrangler.jsonc` has **no `main`** (assets-only Worker). Worker + Durable Object added in M6. | Nothing to run server-side yet; keeps M1 a plain static site. |
| 2026-10-26 | TypeScript pinned to 5.9.x. | typescript-eslint supports `<6.1.0`. |
| 2026-10-26 | Sim tick rate 30 Hz, render interpolates. | Cheaper in the Durable Object, fits 15-20 Hz snapshots, smooth on phones. |
| 2026-10-26 | Sim bans `Math.sin/cos/atan2/pow/exp/log/random` and clocks via ESLint; own `dsin/dcos/datan2` in `src/sim/dmath.ts`. | Identical results on both phones and the server. `+ - * / sqrt` are IEEE-exact. |
| 2026-10-26 | Terrain lighting baked into vertex colours, `MeshBasicMaterial` + fog. No shadow maps, no terrain textures. | Cheapest possible shading on mobile GPUs. |
| 2026-10-26 | Terrain LOD seams hidden with skirts. | Simpler and cheaper than stitched LOD edges. |
| 2026-10-26 | Terrain deltas capped (256); on overflow the two nearest of the oldest deltas are merged, then the weakest dropped. Ids are monotonic; a `compactionEpoch` tells the renderer to rebuild everything. | Bounded sync payload for co-op; deterministic. |
| 2026-10-26 | M1 service worker is a no-cache stub (install/activate only, network passthrough). | Avoids stale builds on the phone while testing. Real offline caching lands in M3. |
| 2026-10-26 | Real post-process bloom deferred to M5c (High preset only). M1 uses additive glow sprites. | Per brief: fake glow on Low/Medium. |
| 2026-10-26 | Branch policy: develop on `claude/elegant-franklin-d9ap5u`; after build + tests pass, fast-forward `main` from it (the brief says to push to main on green). Cloudflare deploys `main`. | Brief: "Push to main only when the build and tests pass". |
| 2026-10-26 | Golden terrain checksum re-recorded after an intentional change to oasis blending (smoothstep 0..0.6). Rule: only update the golden when the terrain *algorithm* changes on purpose, never to hide platform drift. | The golden uses fixed params (not chapter data) so chapter tuning never trips it. |
| 2026-10-26 | Wizards are four fixed looks: Rashid (fire, turban), Yasmin (water, headscarf), Tariq (earth, turban), Farah (air, headscarf). Each is ONE merged vertex-coloured mesh (1 draw call). The element jewel on the headwear differs in SHAPE (flame / drop / block / ring). | User asked for an Arabian look: turbans, headscarves for women. Shape-not-colour keeps it colour-blind safe. Rivals and archers will reuse the builder (M3). |
| 2026-10-26 | Wizard picker is visual-only until M4; every wizard throws the Fireball in M2. | Brief: M2 = ONE spell. Full per-element kits arrive in M4. |
| 2026-10-26 | Sim entity caps (projectiles 32, orbs 120, creatures 24, wells 3, events 160) are single constants in `sim.json`; the per-preset caps in `quality.json` limit only what is DRAWN (nearest orbs first) and particles. | Quality must never change the shared simulation, but presets still need hard caps on cost. |
| 2026-10-26 | Mana sources so far: orbs (ambient + creature drops) and **mana wells**: random, temporary, finite reserves you drain by hovering beside them (beam + HUD arrow guide you). Wild animals as a further mana source are planned for M3 with the chapter creature sets. | User request: mana-drawing opportunities such as wild animals and magic wells appearing randomly. |
| 2026-10-26 | One additive `Points` object (GlowLayer) draws orbs, bolts and particles: a single draw call and the cheap fake bloom. Particle pool hard-capped per preset. | Performance budget. |
| 2026-10-26 | Dev hook `window.__game` exists only under `import.meta.env.DEV`. | Lets headless visual tests stage scenes; stripped from production builds. |
| 2026-10-26 | Efficiency pass after M1 phone test (60 fps on High, little heat): terrain planner replans only when needed; no per-vertex allocations; devicemotion listener only while tilt is on; static screens redraw at 2 Hz; overlay shows JS cpu ms. | User asked to double-check efficiency. |
| 2026-10-26 | Hover height raised 6.5 -> 8.5 and palms shortened (6.5 -> 5.2 units) so flight clears the palm crowns. | Palms were clipping through the tapestry at the oasis spawn. |
| 2026-10-26 | **Castle mana**: castles earn passive income into a shared **castle bank**. Upgrades are paid from the bank first, then the upgrading wizard's pool (co-op: shared bank, personal pools). Player must be within 48 units of their castle. | Matches the brief's "personal pool + shared castle pool" so co-op needs no redesign. |
| 2026-10-26 | **Win metric**: each faction's *captured* mana (orbs, wells, income) as a share of everyone's total. Win at the chapter target share, but only after 6 minutes and 450 total mana. Sudden death (chapter config) lowers the target; 3 minutes later the leader wins. Last castle standing wins immediately. | A balance simulation showed matches ending in under a minute on early noise; passive income also dominated the race, so income was halved. Simulated matches now run ~12-14 min (chapters 1-3). |
| 2026-10-26 | **Castle destruction**: HP 0 drops the castle one tier (HP refilled, 5 s invulnerable, half the bank scattered as orbs). A tier-1 castle is destroyed and its faction eliminated; if it was the last rival, the human wins, if it was yours you lose. | Brief: a destroyed castle drops a tier rather than vanishing, unless it is the last one standing. |
| 2026-10-26 | **Archers** target hostile creatures and enemy projectiles only (never wizards, never wild animals). Hit-scan with a tracer event. A balance test caps archer DPS at 60% of one wizard at every tier/branch combination. | Brief: archers support but never replace the wizard. |
| 2026-10-26 | Rival AI produces a normal `PlayerInput` each tick (same flight and spell code as humans). `autopilot` option runs the human through the same AI for balance and AI-vs-AI tests (M4). | One code path, deterministic, reusable on the Durable Object. |
| 2026-10-26 | Castles sit on flat **pads** (terrain eases to a pad height) and register as **obstacles**: flyers hover over them, projectiles hit them. Props are not generated on pads. | Castles need level ground; keeps terrain a pure function plus capped deltas. |
| 2026-10-26 | Chapter 2 city: a deterministic grid of buildings (`buildingCell`) on a flattened plateau, part of the sim's `surfaceAt` so you fly over rooftops and shots burst on roofs. Structure kits are art code selected by `structureKit`; their tunable numbers live in the chapter JSON. | Rooftop flight needs buildings in the shared sim, not just the renderer. |
| 2026-10-26 | Wild animals (Desert Oryx) are a neutral mana source: they flee, never attack, and archers ignore them. Hostile creatures and wild animals have separate population targets. | Delivers the "wild animals" idea from the user. |
| 2026-10-26 | Offline: the build injects a precache list + content hash into `sw.js`; navigations are network-first (3 s timeout, cache fallback), everything else cache-first with `ignoreVary`. | `Vary: Origin` on module scripts made cached assets miss until `ignoreVary` was set (found by an offline test). |
| 2026-10-26 | Chapters 3-6 are listed in the menu as "Coming soon" (`playableChapters` in `src/data/game.json`). | Content lands in M5a/b; the data and tests already exist. |
| 2026-10-26 | **Mana caps explained and fixed (phone feedback):** a wizard's pool caps at 200 (`player.maxMana`); orbs are not absorbed when full. Upgrades cost 80/170/300/520 and are paid bank-first, so tiers 4-5 were out of reach from the pool alone. Added **Deposit** (hold near your castle: 70 mana/s from pool to castle bank, bank cap 900). Rivals deposit too. HUD shows "Next: cost (bank + mana)". | User could not get past 200 mana to upgrade. |
| 2026-10-26 | **Guided aim:** assist cone widened (cos 0.94 -> 0.86, about 30 degrees), range 200, targets scored by closeness to the aim line with a mild preference for nearer ones; fireballs also home lightly (16% blend per tick, only within 150 units and 50 degrees) toward creatures, nests and enemy wizards. All numbers in `spells.json` `aimAssist`. | User wanted shooting to be more intuitive; stays a nudge, not a lock. |
| 2026-10-26 | **Arabian castle style:** onion domes, round towers with balconies, pointed merlons, arched windows and gate, pencil-point minarets with balconies, gilded finials; warm sandstone palettes per chapter; shaded faces get warm bounce light. | User feedback on castle look. |
| 2026-10-26 | **Conflict economy (phone feedback):** killing a wizard pays a 130-mana bounty (pool first, overflow into the killer's castle bank); a castle losing a tier pays its attacker 70 + 30 x tier, destroying one pays 320. Dying now zeroes ALL personal mana (it drops as orbs anyone can grab) and costs 30% of the castle bank. Credit needs the last hit within 5 s; monsters and friendly fire pay nothing. | User wanted real risk in dying and strong rewards for killing wizards and razing castles. |
| 2026-10-26 | **Palace victory:** owning a tier-5 castle AND having captured the chapter's `palaceWinMana` (3000 / 3200 / 2600 / 2600 / 2400 / 2400) wins outright; rivals can win this way too. Share-race wins now only count after minute 8 (was 6). | User wanted a goal that rewards attacking castles. Autopilot simulations: matches end 9-13 min instead of 6-8. |
| 2026-10-26 | **Weapon tiers:** each wizard attack has 3 tiers bought with personal mana (Fireball -> Blazing Fireball (90) -> Inferno Orb (180)), anywhere on the map. Costs stay <= the 200 pool cap. Each tier: more damage, area and burn, slightly higher mana cost, never worse damage per mana. All numbers live in `spells.json` `tiers`. Rivals buy tiers too. Archer-DPS budget is measured against tier 1. | User asked for 3 tiers of each wizard's attack. Other elements get their 3 tiers in M4. |
| 2026-10-26 | **Evil Genie** (ranged monster): 75 HP, keeps ~55 units away, circles and fires Curse Bolts (11 damage, can be shot down by archers). Drops 45 mana (5 orbs). Monster bolts (faction 99) hurt wizards only: never other monsters, nests or castles. Chapters 1-2 spawn genies, sprites and oryx. | User wanted a more interesting attacker that fires. |
| 2026-10-26 | Terrain tools (Crater / Mound) now sit above the fire button, cost 8 mana each, and can be hidden in Settings ("Terrain tools"). | User request; a mana cost stops free terrain spam. |
